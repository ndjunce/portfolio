# Portfolio — Nicklaus Juncewski

Personal portfolio site. Predictive Analytics Analyst; projects that go from data to a working product.

**Live:** (Vercel URL added after deploy)

## Stack
- Next.js 14 (App Router)
- Tailwind CSS
- Deployed on Vercel

## Local development
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Structure
Single-scroll page (`app/page.js`), data-driven projects array so copy is easy to edit. Sections: Hero, About, Skills, Projects, How I work, Contact.

## Resume PDF
Drop `public/resume.pdf` to activate the footer download link.
